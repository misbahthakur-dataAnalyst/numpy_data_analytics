# NumPy fumdamentals for Data Applications
This repository contains a comprehensive collection of hands-on data manipulation techniques using the **NumPy** library in python. The project focuses on utilizing multi-dimensional arrays, vectorised operations, and structural modifications tailored for analytical workflows.
### Key Concepts Implemented:
* **Array Creation & Structure:** Build 1D and 2D arrays from scratch and inspected their data attributes using properties like '.shape' and '.ndim'.
*  **Data Reshaping & Restructuring:** Applied advanced techniques like '.reshape()' to modify array dimensions without altering the underlying datasets.
*   **Array Slicing & Mathematical Operations:** Executed targeted matrix slicing to extract specific data chunks, row, and columns dynamically.
*    **Vectorised Mathematical Operations:** Performed high-speed statistical computations including '.mean()','sum()', and standard operations directly on array matrices.
